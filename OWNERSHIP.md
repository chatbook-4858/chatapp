# GMC Pvt LTD Ownership

This project is designated by its requester as the property of **GMC Pvt LTD**. The intended owner/operator controls the ChatApp source, brand assets, domain, deployment, data, and product decisions.

## Keep control with the company

- Ensure the GitHub organization/account and this repository are controlled by GMC Pvt LTD.
- Register the domain, cloud accounts, app-store accounts, and service accounts in the company's legal name.
- Use written IP assignment agreements for employees and contractors, and confirm third-party dependency licenses.
- Protect release signing keys and production credentials in company-controlled secret storage.
- Do not publish private keys, API secrets, signing certificates, passwords, database credentials, or customer data in Git.

## Scope and limits

The repository contains an original ChatApp name and logo asset for this project. A repository notice documents the requested ownership designation; legal title, company registration, and trademark rights should be confirmed with the company's counsel and signed agreements.
